# 原图整理后直达编辑工作台

上传位图后先进入一次性「原图整理」（全屏裁剪/旋转/翻转），确认后以默认参数自动像素化并进入编辑工作台；生成参数改为工作台内 Sheet 回访。我们拒绝保留整页「调整底稿」作为主路径，也拒绝进编辑后仍可回退重裁原图，以避免双套生成 UI 和清空编辑历史的高成本回路。

## Considered Options

- 保留生成整页，插在原图整理之后：路径更长，与「完成即进编辑」目标冲突。
- 完成整理后直达编辑，生成参数 Sheet 回访（chosen）。
- 进编辑后仍可回原图整理：需处理历史清空或格子保留，首版不做。

## Consequences

`homeView === 'generation'` 主路径移除；CSV/示例跳过原图整理；应用生成参数会重新像素化并重挂载编辑工作台文档。
