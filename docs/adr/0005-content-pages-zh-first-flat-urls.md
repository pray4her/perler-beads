# 内容页中文先行并使用扁平顶层 URL

站点新增一组围绕核心工具的静态内容页（图纸教程页、色号对照表页、熨烫指南页），每页瞄准一个中文长尾搜索词，目标是把搜索访客引回创作首页使用工具。这批页面只做中文，是「双语路由」规则的例外：英文版仅在确认有真实英文搜索需求时按页补（色号对照表页的五家品牌均为中文圈品牌，预计永远不需要英文版）。URL 采用扁平顶层路径（如 `/color-chart/`）而非 `[lang]/` 路由，根路径即规范地址；页面数量增长到需要枢纽时再引入 `/guide/` 层级。

## Considered Options

- **双语同步（/zh/ + /en/）**：保持双语路由不破，但英文色号对照表无搜索需求、沦为瘦页面，且工作量翻倍。
- **`/guide/` 枢纽结构**：更符合 hub-and-spoke 教科书模型，但仅三个子页时枢纽页自身内容单薄，URL 变长收益小。
- **每色号一个独立页（programmatic SEO）**：长尾覆盖最大，但页面内容极薄，属于搜索引擎明确打击的 scaled content，且与工具关联弱。

## Consequences

- 内容页文案仍需进入 i18n 字典（en 以中文占位补齐，维持 typeof 同构校验），但只生成中文路由。
- i18n 字典的 en 占位不代表该页面有英文版；英文版上线时才建 `/en/xxx/` 路由并补 hreflang。
- 教程页截图由 Playwright 脚本产出（`scripts/`），UI 改版后需重跑以保持截图不过期。
