# 按置信度自动清理外部背景

位图生成底稿时默认尝试清理外部背景：仅在边缘颜色形成高置信度共识时自动应用，低置信度保持原底稿；用户手动触发时使用更积极的阈值，但两者都只排除从画布边界连通的候选区域。成功结果必须显示移除格数并可即时回撤，首次工具操作后专用回撤失效，以免旧快照覆盖后续编辑；CSV 与已保存项目不参与自动清理。

## Considered Options

- 对所有位图强制按边缘主色清理：路径最短，但容易误删贴边主体并残留渐变背景。
- 增加持久开关：控制更显式，但把难以理解的算法参数推给多数用户。
- 高置信度自动处理、低置信度保持原样并保留手动入口（chosen）。

## Consequences

背景识别必须是可测试的纯网格操作；自动与手动入口共享连通性规则，只调整置信度与色差策略。生成阶段的回撤只能存在到首次工具操作。
